# TerraQ website

The terraq.co.za website: a static site in plain HTML, CSS and JavaScript, with no build step.

- `index.html`: home page, products, services, about, contact and the four product pages
- `esg/`: TerraQ ESG interactive demo (fictional data)
- `downloads/`: product sheets (PDF)
- `img/`: photography from the TerraQ company profile

To preview, open `index.html` in a browser. To deploy, connect this repository to Vercel as a static site with no build command and the project root as the output directory.

See `CLAUDE.md` for brand rules, the to-do list and the deployment notes.
